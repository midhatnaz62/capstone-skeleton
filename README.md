# Capstone Skeleton

A production-ready Next.js application built for the Frontend AI Engineering track.

## Live Demo

https://capstone-skeleton-omega.vercel.app/

## Features

- AI Qualification Chat
- Interactive 3D experience
- Custom fullscreen GLSL shader hero
- Responsive navigation
- Keyboard-accessible interactions
- Accessibility and performance improvements
- Playwright end-to-end tests
- Vitest component tests

## Tech Stack

- Next.js
- React
- React Three Fiber
- Three.js
- GLSL
- Tailwind CSS
- Playwright
- Vitest
- Vercel
